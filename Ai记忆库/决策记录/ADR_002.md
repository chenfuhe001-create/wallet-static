# ADR_002：服务器钱包暂不退役；多链/批量/指纹列入待开发

- 日期：2026-11-25
- 状态：生效
- 关联：记忆_002、`开发简报_多链批量指纹.md`、ADR_001

## 背景

本地钱包已完成 BSC/OP 单笔本地签名，用户确认真实链上转账成功。按 ADR_001，本可以在稳定后退役服务器钱包；但用户明确选择「暂不退役」，并要求后续继续补齐旧钱包能力：

1. 多链：Base / Arbitrum / Ethereum / Polygon / Avalanche / Unichain；
2. 批量转账：一个钱包→多个地址、多个钱包→一个地址；
3. 本地指纹：WebAuthn PRF 解锁。

## 决定

1. **服务器钱包保持原样**：不停 `/api/admin/wallet/*`、不删 `wallets.json`/地址本/邮件配置、不动 cron。
2. 上述三项只写需求与记忆，**本轮不实现**；下一位开发者按 `开发简报_多链批量指纹.md` 执行。
3. 开发简报是临时文档，全部验收通过后删除；长期结论留在本 ADR 与 `记忆_002`。
4. 安全红线不变：密码/私钥/PRF 不离开浏览器；多链常量只认客户端注册表；批量非原子、不自动重发已广播交易。

## 理由

- 用户尚未要求服务器退役；两套并存可作为回退。
- 一次性把多链/批量/指纹做完回归面太大，先固化需求再分阶段开发更稳。
- 临时文档避免长期维护过期设计；验收后删除，信息进记忆/ADR。

## 排除了什么

- 现在就退役服务器钱包：用户明确选择暂不退役。
- 本轮直接实现三项功能：用户明确要求先写进记忆、等下一个开发者。
- 把开发简报当长期文档保留：用户要求开发好后可删除。
