# ADR_001：钱包改为完全本地签名，独立静态站，服务器钱包暂不退役

- 日期：2026-11-25
- 状态：生效
- 关联：记忆_001、web `ADR_015`

## 背景

服务器钱包虽然做了加密、限速、地址比对，但服务器被 root 时密码、私钥、签名权都在攻击者手里。仅在服务器运行前和 GitHub 对齐只能检测篡改，不能阻止 root 在签名时换收款地址。

## 决定

1. 新建独立公开仓库 `wallet-static`，部署 GitHub Pages，与 API 服务器分离。
2. 浏览器内完成保险箱解密、BSC 交易签名、OP Circle v0.8 AA（permit/7702/UserOp）签名；只把已签名交易/UserOp 直连公共 RPC/bundler。
3. 保险箱格式与 `wallet_core.py` 兼容，可直接导入现有 `wallets.json`；私钥只按需生成本地二维码。
4. 增加本地改密/重新加密，迁移后可立即轮换旧密码。
5. 服务器钱包**保持原样**；等用户真实 canary 成功、确认稳定后再停接口/清理数据。

## 理由

- 私钥不落在服务器，服务器被 root 也拿不到私钥；已签名交易不可篡改。
- 浏览器直连 publicnode/Pimlico 已经实测可用，不需要后端代理。
- 兼容现有保险箱，迁移不需要导出明文私钥。
- 保留服务器钱包可回退，降低一次性切换风险。

## 排除了什么

- 只在服务器上加签名校验：root 可绕过，签名时仍可作恶。
- 直接删除服务器钱包：迁移未验证前风险太高。
- 一次把地址本/批量等全部功能做完：先 BSC/OP 单笔，降低回归面。
- 用服务器代理 RPC/bundler：会让服务器重新进入信任链。
